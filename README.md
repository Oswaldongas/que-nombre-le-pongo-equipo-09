# que-nombre-le-pongo-equipo-09
Juego desarrollado en Python en el que el jugador debe adivinar un número secreto generado aleatoriamente. Incluye tres niveles de dificultad, pistas para indicar si el número ingresado es mayor o menor, un sistema de puntuación según los intentos utilizados y una tabla con los tres mejores resultados de la sesión. Permite jugar varias rondas consecutivas.
